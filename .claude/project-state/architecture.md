# Architecture

- **Build:** Astro 7.4.4 static output, `build.format: 'file'` (pages are `privacy.html` etc.; Cloudflare Pages serves them at `/privacy`), `trailingSlash: 'never'`, `inlineStylesheets: 'never'`, `vite.build.assetsInlineLimit: 0` (no inline scripts or styles, so the CSP stays strict). Markdown uses `unified()` from `@astrojs/markdown-remark` with `src/lib/remark-legal.mjs`.
- **Styling:** `src/styles/tokens.css` (every token; colours via `light-dark()` with `color-scheme` on `:root`; system by default, `data-theme` forces light/dark; WCAG roles `--primary-ink`, `--btn-bg`, `--herb-ink`, `--stamp-paper`, `--todo-ink`), `fonts.css` (self-hosted faces + metric-matched fallbacks), `base.css` (reset, type roles, links, focus, layout primitives, `.defer-render`, view transitions, print), `brand.css` (glyph colours, wordmark assembly, seal, loader). Components use Astro scoped styles; a class passed to a child component must be targeted with `:global()`.
- **Theme:** `src/scripts/theme.js`, inlined in `<head>` (its SHA-256 is in `public/_headers`; `npm run csp:hash` updates it): reads `localStorage['aftertaste-theme']`, sets `data-theme`, updates `theme-color` metas and the toggle's `aria-pressed`, handles toggle clicks by delegation, adds `html.js`.
- **Landing JS:** `src/scripts/landing.ts` (1.5 KB gz): IntersectionObserver stamp presses, the time-based receipt print fallback, the "What should we eat?" demo.
- **Motion:** CSS keyframes from the brand/app motion tokens; the receipt uses a CSS view timeline (`--print`, longhand properties only) on wide and tall viewports, else a timed print. Page navigation uses cross-document View Transitions (`@view-transition`), no JS. Everything has a reduced-motion rule.
- **Legal:** content collection `legal` (`src/content.config.ts`, glob loader over `src/content/legal/*.md`, zod from `astro/zod`), rendered by `src/components/LegalPage.astro` for `/privacy` and `/terms`.
- **SEO/platform:** `BaseLayout.astro` (title, description, canonical, OG/Twitter, icons, manifest, JSON-LD slot); `@astrojs/sitemap` (404 excluded); `public/robots.txt`; OG PNGs in `public/og/` (`npm run og`); icons from `brand/app-icon-1024.png` and `public/favicon.svg` (`npm run icons`).
- **Headers/redirects:** `public/_headers` (CSP, HSTS, security headers, caching), `public/_redirects` (trailing slashes, aliases). `www` → apex needs a Cloudflare Redirect Rule.
- **Gates and audits:** `scripts/` (see README). `scripts/serve-dist.mjs` mimics Pages (clean URLs, `_headers`, `_redirects`, 404) for audits.
